# Теплорасчёт стены — Android-приложение

Офлайн-приложение: теплотехнический расчёт многослойной наружной стены
(толщина утеплителя, распределение температуры, упругость пара, летняя теплоустойчивость).
Работает без интернета. Android 8.0 и новее.

## Способ 1. Сборка через GitHub (ничего не нужно устанавливать)

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (кнопка **New**).
2. На странице репозитория: **Add file → Upload files** — перетащите *всё содержимое*
   этой папки (включая скрытую папку `.github`) и нажмите **Commit changes**.
   Если браузер не загружает папку `.github`, создайте файл
   `.github/workflows/build-apk.yml` через **Add file → Create new file** и вставьте его текст.
3. Откройте вкладку **Actions** — сборка запустится сама (3–5 минут).
4. Откройте завершённую сборку (зелёная галочка), внизу в разделе **Artifacts**
   скачайте `TeploRaschet-apk` — внутри архива файл `app-debug.apk`.
5. Перекиньте `app-debug.apk` на телефон и откройте его. Android попросит разрешить
   установку из неизвестных источников — разрешите для файлового менеджера/браузера.

## Способ 2. Android Studio

Откройте эту папку в Android Studio (**File → Open**), дождитесь синхронизации,
затем **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.

## Как изменить расчёт

Весь расчёт и интерфейс — в файле `app/src/main/assets/index.html`.
После изменения файла соберите APK заново.
Чтобы выпустить новую версию поверх старой, увеличьте `versionCode` в `app/build.gradle.kts`.
