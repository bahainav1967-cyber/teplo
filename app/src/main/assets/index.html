Как считается

Rотр (сан.) = (tв − tн) / (Δtн · αв), αв = 8,7; αн = 23 Вт/(м²·°С)

ГСОП = (tв − tн) · Zо.п.; Rотр (энерг.) = 2,4 при ГСОП ≤ 3000, иначе 3,0. Принимается большее из двух.

δх = (Rотр − 1/αв − ΣRi − 1/αн) · λх; Ri = δi/λi; D = Σ Ri·Si

τx = tв − (tв − tн.р)·(1/αв + ΣR до сечения)/R0

E = 1,84·10¹¹·exp(−5330/(273 + t)), Па; e = eв − (ΣRп до сечения / Rп0)(eв − eн); Rп = δ/μ, Rпв = 0,0267, Rпн = 0,0052

Y1 = (R1S1² + αв)/(1 + R1αв), Yi = (RiSi² + Yi−1)/(1 + RiYi−1); при Di ≥ 1 Yi = Si

ν = 0,9·e^(D/√2)·(S1+αв)(S2+Y1)…(αн.л+Yn) / [(S1+Y1)…(Sn+Yn)·αн.л]; αн.л = 1,16(5 + 10√v)

Atн.расч = 0,5·Atн + ρ(Imax − Iср)/αн.л; Aτв = Atн.расч/ν ≤ Aτв.тр = 2,5 − 0,1(tн − 21)
